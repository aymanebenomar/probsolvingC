# qsort

Reimplement the standard qsort so it orders elements of any width through a caller supplied comparator

```c
void qsort(void *base, size_t nmemb, size_t size, int (*cmp)(const void *, const void *))
```

**Difficulty:** 5/5
**Allowed functions:** none

Solved as level 4 of the sort-and-search challenge.
